# Active Projects

## Go lang

### Browser Server

Browser Server is a self-hosted personal-data service with a web app and browser extensions. It stores todos, bookmarks, browsing history, password-wallet entries, screenshots, and per-domain usage analytics in local SQLite databases.

- [GitHub](https://github.com/shishtpal/browser-server)

### Clipboard Monitor

A high-performance Windows clipboard monitoring library and toolkit written in Go. Captures clipboard changes in real-time and processes them asynchronously through a concurrent queue.

- [GitHub](https://github.com/shishtpal/clipboard-monitor)

## Zig Lang

### zpy

ZPy is a Python-like language interpreter written in Zig

- [GitHub](https://github.com/shishtpal/zpy)
- [Website](https://shishtpal.github.io/zpy/)

### zimage

A fast, lightweight image viewer built with Zig and Raylib. Features a gallery mode with thumbnail grid, pan/zoom controls, and support for modern image formats like WebP and AVIF

- [GitHub](https://github.com/shishtpal/zimage)

### zserve

A simple, lightweight HTTP file server written in Zig. Serves static files and provides directory listings with a clean web interface.

- [GitHub](https://github.com/shishtpal/zserve)
- [Website](https://shishtpal.github.io/zserve/)

### zgui

ZGUI is a Zig desktop GUI application using raylib and raygui

- [GitHub](https://github.com/shishtpal/zgui)

### zdown

A fast, modular download tool written in Zig with support for parallel downloads, resume, and checksum verification.

- [GitHub](https://github.com/shishtpal/zdown)

### zchrome

`zchrome` provides a pure Zig implementation of the Chrome DevTools Protocol client, enabling programmatic control of Chrome/Chromium browsers. Use it for browser automation, web scraping, testing, and more.

- [GitHub](https://github.com/shishtpal/zchrome)
- [Website](https://shishtpal.github.io/zchrome/)

### zmouse

A command-line input controller for Windows that interprets text commands and executes corresponding mouse and keyboard actions using Win32 API via Zig's C interop. Includes recording and playback functionality.

- [GitHub](https://github.com/shishtpal/zmouse)
- [Website](https://shishtpal.github.io/zmouse/)
